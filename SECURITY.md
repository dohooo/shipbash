# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Never report one in a
public issue, pull request or discussion.

Please include:

- what is affected: the hosted service at app.shipbash.dev, a self-hosted
  deployment (with its version or commit), or the `shipbash` CLI (with its
  version);
- the steps to reproduce it, and a proof of concept if you have one;
- what an attacker could do with it.

We acknowledge every report, keep you updated while we fix it, and credit you
in the release notes if you want.

## Supported versions

Fixes go into the latest release of ShipBash and the latest version of the
`shipbash` CLI.
